# AGENTS

This workspace follows a layered documentation approach.

## Context Files
- `docs/PRD.md`: product requirements, goals, and acceptance criteria.
- `docs/PRODUCT_BRIEF.md`: concise positioning and value proposition.
- `docs/UX_NOTES.md`: visual and interaction notes.
- `docs/TECHNICAL_NOTES.md`: rendering and data model details.
- `CHANGELOG.md`: release notes.

## Execution Notes
- Keep UI minimal and globe-first.
- Preserve immediate feedback; no explicit apply buttons.
- Encode view state in permalinks.
- Maintain changelog updates for releases.
